# Python Template

## Documentazione

Per leggere la documentazione, è necessario installare mkdocs e avviarlo.

### Installazione di mkdocs

```bash
pipx install mkdocs
pipx inject mkdocs mkdocs-material
pipx inject mkdocs mkdocs-mermaid2-plugin
```

### Avvio della documentazione

```bash
mkdocs serve
```
