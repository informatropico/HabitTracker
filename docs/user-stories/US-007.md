# US-007 — Habit non più dichiarati
[Torna alla Home](../index.md)

## User Story

**Come** Utente, **voglio** visualizzare gli habit rispettati a lungo ma non più dichiarati, **così da** capire se siano stati assorbiti nella routine o abbandonati.
