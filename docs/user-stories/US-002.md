# US-002 — Consuntivo serale degli habit

## User Story

**Come** Utente, **voglio** dichiarare ogni sera quali habit ho rispettato e quali no, **così da** avere un feedback sulla mia giornata.

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-002-01 | Il sistema **deve** permettere di indicare per ogni habit della sessione mattutina (US-001) se è stato rispettato | Proposto |
| RF-002-02 | Il sistema **deve** permettere di indicare per ogni habit della sessione mattutina (US-001) se non è stato rispettato | Proposto |
| RF-002-03 | Il sistema **deve** mostrare nella sezione serale di ogni giornata gli habit rispettati | Proposto |
| RF-002-04 | Il sistema **deve** mostrare nella sezione serale di ogni giornata gli habit non rispettati | Proposto |
| RF-002-05 | Il sistema **deve** permettere di modificare la scelta fatta su un habit e riportarlo allo stato in corso, rispettato o non rispettato | Proposto |
| RF-002-06 | Il sistema **deve** lasciare "Attivi" gli habit che non sono stati indicati come rispettati o non rispettati | Proposto |
| RF-002-07 | Il sistema **dovrebbe** registrare la data e l'ora dell'ultima modifica per ogni giornata | Proposto |
