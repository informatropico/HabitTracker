# US-015 — Visualizzazione habit attivi in giornate precedenti non completati

## User Story

**Come** Utente, **voglio** visualizzare gli habit rimasti in stato "In corso" nelle giornate precedenti, **così da** tenere traccia dei giorni non completati e poterli aggiornare.

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-015-01 | Il sistema **dovrebbe** visualizzare l'elenco delle giornate precedenti che contengono almeno un habit in stato "In corso" | Proposto |
| RF-015-02 | Il sistema **dovrebbe** indicare per ogni giornata il numero di habit rimasti in stato "In corso" | Proposto |
| RF-015-03 | Il sistema **dovrebbe** permettere di accedere direttamente alla giornata selezionata per completarla (US-014) | Proposto |
