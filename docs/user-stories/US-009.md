# US-009 — Marcatura habit abbandonato
[Torna alla Home](../index.md)

## User Story

**Come** Utente, **voglio** indicare un habit come abbandonato, **così che** non venga più considerato nelle statistiche.

## Metadati

| Campo | Valore |
|-------|--------|
| ID | US-009 |
| Stato | Bozza |
| Priorità | Alta |
| Data creazione | 2026-05-26 |
| Data ultima modifica | — |

## Dipendenze

| ID | Titolo | Relazione |
|----|--------|-----------|
| US-016 | Accesso all'elenco degli habit | Dipende da — l'azione viene eseguita dall'elenco degli habit |

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-009-01 | Il sistema **deve** permettermi di accedere all'elenco degli habit (US-016) | Proposto |
| RF-009-02 | Il sistema **deve** permettere di dichiarare un habit come Abbandonato | Proposto |
| RF-009-03 | Il sistema **deve** registrare la data di cambio stato dell'habit | Proposto |
| RF-009-04 | Il sistema **deve** escludere un habit Abbandonato dalle statistiche (US-005, US-006, US-007) dalla data di cambio stato in poi, mantenendone la visibilità in US-004 | Proposto |
| RF-009-05 | Il sistema **deve** escludere un habit Abbandonato dalla selezione degli habit giornaliera | Proposto |
