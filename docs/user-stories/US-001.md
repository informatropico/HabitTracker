# US-001 — Dichiarazione mattutina degli habit
[Torna alla Home](../index.md)

## User Story

**Come** Utente, **voglio** dichiarare ogni mattina fino a 5 habit da rispettare nella giornata, **così da** creare la motivazione a restare focalizzato.

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-001-01 | Il sistema **deve** permettere di avviare la sessione mattutina di "Intention" | Proposto |
| RF-001-02 | Il sistema **deve** permettere di visualizzare gli habit attivi selezionabili | Proposto |
| RF-001-03 | Il sistema **deve** permettere di selezionare un habit da inserire per la giornata odierna | Proposto |
| RF-001-04 | Il sistema **deve** impedire di inserire un habit più di una volta | Proposto |
| RF-001-05 | Il sistema **deve** impedire di inserire habit non attivi | Proposto |
| RF-001-06 | Il sistema **deve** impedire di inserire più di 5 habit | Proposto |
| RF-001-07 | Il sistema **deve** permettere di lasciare una giornata senza habit da rispettare | Proposto |
| RF-001-08 | Il sistema **deve** permettere di rimuovere un habit inserito se ancora attiva la sessione | Proposto |
| RF-001-09 | Il sistema **dovrebbe** permettere sempre di modificare la conformazione degli habit mattutini se la sessione è ancora attiva | Proposto |
| RF-001-10 | Il sistema **deve** salvare i dati quando l'utente conferma la fine della sessione | Proposto |
| RF-001-11 | Il sistema **deve** copiare nella sezione serale gli habit scelti dopo il salvataggio della sessione | Proposto |
| RF-001-12 | Il sistema **dovrebbe** registrare la data e ora del salvataggio della sessione | Proposto |
| RF-001-13 | Il sistema **deve** impedire di modificare una sezione mattutina se la sessione è stata salvata | Proposto |
| RF-001-14 | Il sistema **dovrebbe** permettere di annullare una sessione in corso | Proposto |

## Note e Domande Aperte

!!! nota
    La sessione mattutina è importante per "forzare" l'utente a fare una scelta e cercare di rispettarla.
    Se può modificare in ogni momento la composizione mattutina l'utilità del sistema diventa dubbio. Si tratta di prendersi un impegno con se stessi.
