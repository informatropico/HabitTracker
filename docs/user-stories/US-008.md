# US-008 — Archiviazione habit come routine

## User Story

**Come** Utente, **voglio** dichiarare che un habit è diventato una routine, **così da** celebrare il successo raggiunto e archiviarlo.

## Metadati

| Campo | Valore |
|-------|--------|
| ID | US-008 |
| Stato | Bozza |
| Priorità | — |
| Data creazione | — |
| Data ultima modifica | — |

## Dipendenze

| ID | Titolo | Relazione |
|----|--------|-----------|
| US-016 | Accesso all'elenco degli habit | Dipende da — l'azione viene eseguita dall'elenco degli habit |

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-008-01 | Il sistema **dovrebbe** permettermi di accedere all'elenco degli habit (US-016) | Proposto |
| RF-008-02 | Il sistema **dovrebbe** permettere di dichiarare un habit come Assimilato | Proposto |
| RF-008-03 | Il sistema **dovrebbe** registrare la data di cambio stato dell'habit | Proposto |
| RF-008-04 | Il sistema **dovrebbe** escludere un habit Assimilato dalle statistiche (US-005, US-006, US-007) dalla data di cambio stato in poi | Proposto |
| RF-008-05 | Il sistema **dovrebbe** escludere un habit Assimilato dalla selezione degli habit giornaliera | Proposto |
