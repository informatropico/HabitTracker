# US-003 — Aggiunta a posteriori di habit rispettati

## User Story

**Come** Utente, **voglio** aggiungere ogni sera habit che ho rispettato ma che non avevo dichiarato al mattino, **così da** non perdere il tracciamento di comportamenti positivi non pianificati.

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-003-01 | Il sistema **deve** permettere di aggiungere un habit attivo rispettato ma non dichiarato la mattina | Proposto |
| RF-003-02 | Il sistema **deve** permettere di inserire più di 5 habit nella sezione serale | Proposto |
| RF-003-03 | Il sistema **deve** permettere di lasciare vuota una sezione serale solo se è vuota quella mattutina | Proposto |
| RF-003-04 | Il sistema **deve** impedire di aggiungere un habit nella sezione serale se già presente dalla sessione mattutina | Proposto |
| RF-003-05 | Il sistema **dovrebbe** registrare la data e l'ora dell'ultima modifica per ogni giornata | Proposto |
