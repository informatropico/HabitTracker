# US-012 — Riportare "In corso" un habit Abbandonato o Assimilato

## User Story

**Come** Utente, **voglio** riportare allo stato "In corso" un habit precedentemente abbandonato o assimilato, **così da** poterlo tracciare nuovamente in modo attivo.

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-012-01 | Il sistema **dovrebbe** permettere di riportare "In corso" un habit "Abbandonato" o "Assimilato" | Proposto |
| RF-012-02 | Il sistema **dovrebbe** registrare la data di cambio stato | Proposto |
| RF-012-03 | Il sistema **dovrebbe** considerare l'habit rispettato nelle statistiche dalla data di creazione dell'habit | Proposto |

## Note e Domande Aperte

> RF-012-03: chiarire se il ripristino "In corso" includa lo storico precedente all'abbandono/assimilazione nel calcolo delle statistiche, o parta da zero dalla data di ripristino.
