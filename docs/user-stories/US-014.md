# US-014 — Modifica di una giornata precedente

## User Story

**Come** Utente, **voglio** modificare gli habit di una giornata precedente a quella odierna, **così da** correggere o integrare dati non compilati o inseriti erroneamente.

## Dipendenze

| ID | Titolo | Relazione |
|----|--------|-----------|
| US-001 | Dichiarazione mattutina degli habit | Dipende da — replica le stesse regole della sezione mattutina |
| US-002 | Consuntivo serale degli habit | Dipende da — replica le stesse regole della sezione serale |
| US-003 | Aggiunta a posteriori di habit rispettati | Dipende da — replica le stesse regole dell'aggiunta serale |

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-014-01 | Il sistema **dovrebbe** permettere di accedere alle giornate precedenti a quella odierna | Proposto |
| RF-014-02 | Il sistema **dovrebbe** permettere di modificare la sezione mattutina di una giornata precedente (US-001) | Proposto |
| RF-014-03 | Il sistema **dovrebbe** permettere di modificare la sezione serale di una giornata precedente (US-002, US-003) | Proposto |
| RF-014-04 | Il sistema **dovrebbe** registrare la data e l'ora dell'ultima modifica per ogni giornata | Proposto |
