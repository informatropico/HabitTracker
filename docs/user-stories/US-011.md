# US-011 — Aggiunta di un nuovo habit

## User Story

**Come** Utente, **voglio** aggiungere un nuovo habit da introdurre nella mia routine, **così da** avere un supporto durante la fase di adozione della nuova abitudine.

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-011-01 | Il sistema **dovrebbe** permettere di inserire la descrizione del nuovo habit | Proposto |
| RF-011-02 | Il sistema **dovrebbe** permettere una descrizione lunga al massimo 30 caratteri | Proposto |
| RF-011-03 | Il sistema **dovrebbe** cercare habit già inseriti con la stessa descrizione per evitare duplicati | Proposto |
| RF-011-04 | Il sistema **dovrebbe** permettere di selezionare la categoria del nuovo habit tra (Sport, Benessere, Salute, Studio, Lavoro, Altro) | Proposto |
| RF-011-05 | Il sistema **dovrebbe** salvare il nuovo habit con stato "In corso" | Proposto |
