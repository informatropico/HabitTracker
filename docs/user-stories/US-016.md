# US-016 — Accesso all'elenco degli habit

## User Story

**Come** Utente, **voglio** accedere all'elenco di tutti i miei habit, **così da** avere una visione completa del loro stato e poterli gestire.

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-016-01 | Il sistema **dovrebbe** visualizzare l'elenco di tutti gli habit presenti nel sistema | Proposto |
| RF-016-02 | Il sistema **dovrebbe** indicare per ogni habit il suo stato (In corso, Assimilato, Abbandonato) | Proposto |
| RF-016-03 | Il sistema **dovrebbe** indicare per ogni habit la sua categoria | Proposto |
| RF-016-04 | Il sistema **dovrebbe** permettere di filtrare gli habit per stato | Proposto |
| RF-016-05 | Il sistema **dovrebbe** permettere di accedere al dettaglio statistiche di un habit (US-004) | Proposto |
