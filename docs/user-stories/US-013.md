# US-013 — Accedere alla giornata in corso
[Torna alla Home](../index.md)

## User Story

**Come** Utente, **voglio** accedere alla giornata in corso, **così da** poter compilare e consultare le sezioni mattutina e serale del giorno attuale.

## Dipendenze

| ID | Titolo | Relazione |
|----|--------|-----------|

| US-002 | Consuntivo serale degli habit | Dipende da — gestisce la sezione serale |
| US-003 | Aggiunta a posteriori di habit rispettati | Dipende da — gestisce l'aggiunta serale non pianificata |

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-013-01 | Il sistema **deve** visualizzare la giornata in corso con le sezioni mattutina e serale ad ogni accesso | Proposto |
| RF-013-02 | Il sistema **deve** permettere in ogni momento di segnare come rispettato un habit nella sezione serale (US-002) | Proposto |
| RF-013-03 | Il sistema **deve** permettere in ogni momento di segnare come non rispettato un habit nella sezione serale (US-002) | Proposto |
| RF-013-04 | Il sistema **deve** permettere di creare la sessione mattutina (US-001) | Proposto |
| RF-013-05 | Il sistema **deve** impedire di modificare la sezione mattutina se la sessione è stata creata (US-001) | Proposto |
| RF-013-06 | Il sistema **deve** permettere di modificare la sezione serale (US-002, US-003) | Proposto |
| RF-013-07 | Il sistema **dovrebbe** registrare la data e l'ora dell'ultima modifica per ogni giornata | Proposto |
