# US-004 — Consultazione statistiche per habit
[Torna alla Home](../index.md)

## User Story

**Come** Utente, **voglio** consultare le statistiche di ogni habit, **così da** verificarne l'andamento nel tempo.

## Requisiti Funzionali

| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-004-01 | Il sistema **deve** permettere di selezionare uno degli habit caricati a sistema | Proposto |
| RF-004-02 | Il sistema **deve** visualizzare lo stato dell'habit (In corso, Assimilato, Abbandonato) | Proposto |
| RF-004-03 | Il sistema **dovrebbe** visualizzare la data di inserimento dell'habit | Proposto |
| RF-004-04 | Il sistema **dovrebbe** visualizzare il log dei cambi di stato dell'habit per data | Proposto |
| RF-004-05 | Il sistema **deve** visualizzare il numero di giorni in cui è stato selezionato l'habit la mattina | Proposto |
| RF-004-06 | Il sistema **deve** visualizzare il numero di giorni in cui quell'habit è stato rispettato | Proposto |
| RF-004-07 | Il sistema **deve** visualizzare il numero di giorni in cui quell'habit non è stato rispettato | Proposto |
| RF-004-08 | Il sistema **deve** visualizzare il numero di giorni in cui quell'habit è stato inserito direttamente la sera | Proposto |
| RF-004-09 | Il sistema **dovrebbe** mostrare il dettaglio giornaliero di quell'habit: elencare i giorni in cui è comparso e l'esito (rispettato, non rispettato, aggiunto la sera) | Proposto |
| RF-004-10 | Il sistema **dovrebbe** permettere di filtrare il risultato su tutto l'arco temporale, gli ultimi 30 giorni o gli ultimi 90 giorni | Proposto |
