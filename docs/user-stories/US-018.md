# US-018 — Eliminazione definitiva di un habit mai utilizzato
[Torna alla Home](../index.md)

## User Story
**Come** Utente, **voglio** eliminare definitivamente un habit che non ho mai selezionato in nessuna giornata, **così da** tenere la lista degli habit pulita da voci create per errore o non più desiderate prima ancora di essere state utilizzate.

## Requisiti Funzionali
| ID Requisito | Descrizione | Stato |
|--------------|-------------|-------|
| RF-018-01 | Il sistema **deve** permettere di eliminare definitivamente un habit che non sia mai stato selezionato in nessun record di giornata | Proposto |
| RF-018-02 | Il sistema **deve** impedire l'eliminazione di un habit che risulti selezionato in almeno un record di giornata | Proposto |
| RF-018-03 | Il sistema **deve** richiedere una conferma esplicita prima di procedere con l'eliminazione | Proposto |
| RF-018-04 | Il sistema **deve** rimuovere l'habit in modo permanente e irreversibile, senza possibilità di recupero | Proposto |
| RF-018-05 | Il sistema **dovrebbe** comunicare chiaramente all'utente che l'eliminazione è definitiva prima della conferma | Proposto |

## Note e Domande Aperte
> L'eliminazione è regolata da BR-003 (aggiornata il 2026-05-28): la transizione `[qualsiasi stato] → [eliminato]` è ammessa esclusivamente se l'habit non compare in nessun record di giornata, indipendentemente dallo stato corrente.
