Aggiungi un requisito non funzionale. L'utente fornisce la descrizione del requisito.

Esegui le seguenti azioni:
1. Leggi `docs/requirements/non-functional.md`
2. Classifica il NFR per categoria: Performance, Sicurezza, Usabilità, Manutenibilità, Portabilità
3. Assegna ID progressivo (es. NFR-001)
4. Verifica se il NFR impatta US esistenti e segnalalo esplicitamente
5. Mostra bozza e chiedi conferma prima di aggiornare il file
