Estrai e formalizza i requisiti funzionali per una User Story esistente. L'utente fornisce l'ID della US (es. US-001).

Esegui le seguenti azioni:
1. Leggi il file `docs/user-stories/[US-ID].md`
2. Leggi `docs/requirements/business-rules.md` per verificare BR applicabili
3. Proponi i requisiti funzionali con formalismo:
   - "Il sistema **deve**" → requisito obbligatorio
   - "Il sistema **dovrebbe**" → requisito raccomandato
   - "Il sistema **può**" → requisito facoltativo
4. Assegna ID progressivi (es. RF-017-01, RF-017-02...)
5. Segnala se un RF dipende da o contraddice RF esistenti in altre US
6. Mostra la bozza e chiedi conferma prima di aggiornare il file
