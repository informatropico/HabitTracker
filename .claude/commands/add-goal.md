Formalizza un obiettivo di business. L'utente fornisce la descrizione dell'obiettivo.

1. Leggi `docs/business/objectives.md`
2. Assegna ID progressivo (es. OB-001)
3. Formalizza con:
   - Descrizione chiara dell'obiettivo
   - Metrica di successo se identificabile
   - US collegate se già esistenti
4. Mostra bozza e chiedi conferma prima di aggiornare il file
