Apri una change request formale. L'utente fornisce la descrizione del cambiamento richiesto.

Esegui le seguenti azioni:
1. Leggi i file in `docs/changes/` per identificare l'ID successivo
2. Compila il template CR con:
   - ID (es. CR-001), Stato: Aperta, Data apertura
   - Descrizione del cambiamento
   - Artefatti impattati (US, RF, BR, ADR) con modifica richiesta per ognuno
   - Valutazione impatto: Basso / Medio / Alto con motivazione
3. Mostra bozza e chiedi conferma prima di salvare in `docs/changes/CR-NNN.md`
